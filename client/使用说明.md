# 神四客户端（无启动器音乐）

## 使用方法

1. 将整个“神四客户端”文件夹解压到可写目录，勿在压缩包里直接启动。
2. 双击“神四启动器.exe”，确认选中“神四-1.12.2”。
3. 按自己的账号方式登录。已取消模板强制 LittleSkin 登录；神四使用 AuthMe 服内登录，未内置任何账号密码。
4. 启动后进入“多人游戏”，列表中已添加“神四”：t7.sjcmc.cn:35237。
5. Minecraft 1.12.2 / Forge 14.23.5.2847 建议使用 64 位 Java 8。若电脑没有 Java 8，使用 PCL 提示的 Java 管理/自动下载功能；首次补齐运行环境需要联网。

## 本次调整

- 启动器标题、版本目录、版本 ID 与服务器列表改为神四。
- 删除启动器的 MP3，并关闭自动播放与启动时播放、音量设为 0；原版游戏声音资源保留。
- 保留模板全部 5 个 MOD、DragonCore 图片/模型/字体与资源配置，未替换服务器端插件。
- 清理模板旧存档、截图、日志、皮肤缓存及个人运行数据，原模板 ZIP 保持原样。
- 保留模板有效的 Faithful 资源包选择，以及全部 DragonCore 资源。
