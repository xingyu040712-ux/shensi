# 神四装备符文同一行改造与验收

完成日期：2026-10-19。

神四所有带符文栏的装备模板已改为“符文前缀与全部孔位在同一条 Lore 中”。原孔数、装备属性、等级要求、宝石栏位及其他说明保持不变。玩家旧装备在使用符文页面时自动整理，整理前保存完整物品副本；没有批量扫描玩家库存或仓库。

## 实际显示

```text
空孔：符文➱「✰」 「✰」 「✰」
镶嵌：符文➱「ℭⅠ」 「℘Ⅱ」 「℘Ⅰ」
拆卸：符文➱「ℭⅠ」 「✰」 「℘Ⅰ」
```

上述混合符文示例来自测试账号的真实 GUI 操作；复装、关闭界面和重登后保持同一行。服务端用于识别符文的隐藏标记和 NBT 均保留。

## 修改范围

修改 8 份文件：6 份 MythicMobs 装备文件、YeeGem 符文页面配置，以及现有 CxsRuneCompat 兼容插件。YeeGem 符文定义、属性数值、成功率、孔位定义和等级配置未改。

- `plugins/MythicMobs/Items/世界奇点.yml`
- `plugins/MythicMobs/Items/掉落.yml`
- `plugins/MythicMobs/Items/黄金古城迁入.yml`
- `plugins/MythicMobs/Items/怪物掉落装备/7第七层.yml`
- `plugins/MythicMobs/Items/新增/新天使装备.yml`
- `plugins/MythicMobs/Items/魔能系列/魔能装备.yml`
- `plugins/YeeGem/gui/符文页面.yml`
- `plugins/CxsRuneCompat-1.0.jar`（保留文件名，内部版本为 1.2）

共 71 条装备定义，对应 70 个实际物品 ID。原有“终焉烈焰之翼”在两份文件中重复定义，两份配置均已整理，服务端按实际加载的定义验证，未改动物品 ID 或既有覆盖关系。

CxsRuneCompat 已由拆行逻辑调整为同一行整理：处理装备放入、镶嵌、拆卸和关闭界面后的物品；只改变符文区域的 Lore 分行，不重新生成符文 NBT，不改变物品数量。整理失败或备份校验失败时保留原物品。关闭页面后调用现有 YeeGem 属性刷新接口。
