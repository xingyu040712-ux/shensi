## 文件与使用

- `patches/config-changes.patch`：4 个目标配置的 UTF-8/LF 差异，已在原配置副本中用 git apply 重放并与部署版本逐字核对。应用前备份并检查上下文；如果目标文件后来改过，先合并差异。
- `fragments/`：五种卡的 Guo 触发和 MythicMobs 物品定义，仅为合并参考，不能覆盖整份原配置。
- `deployment-manifest.json`：实际部署前后原文件 SHA-256；公开文件的 LF 正文哈希见仓库根校验表。
- `verification/`：合成测试角色的卡片消费、续期、登录与到期回收证据。没有公开真实玩家数据或权限组完整列表。

到期测试只调整合成测试角色的会员起算时间，不改服务器时钟。在线检查有调度周期，离线到期在再次登录时检查。永久会员、跨级切换未验收，未做回退测试。

## Windows 权限标签

另查明目标 Java 带 Low 强制完整性标签，导致 H2 权限库只读。备份后仅将目标 java.exe 标签改为 Medium，二进制 SHA-256 不变；随后重启，实际新玩家注册和权限写入成功。

这项修改属于文件系统安全标签，不能通过 Git 文件内容表达。仅在复现同一 Low 标签故障、确认目标和备份后，对具体目标运行 `icacls "神四根目录\zulu8.0.422\bin\java.exe" /setintegritylevel M`；不要递归重置权限或覆盖玩家数据库。
